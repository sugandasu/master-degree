What is WILD?

WILD is a web-based wildfire detection tool that uses a large vision AI model to analyze uploaded images for signs of fire, smoke, or clear conditions.

It is intended to assist field workers, researchers, and community members in quickly assessing photographic evidence from drones, cameras, or mobile devices.

The system provides a classification label along with a confidence score and a short natural-language summary of what was detected in the image.

How It Works
  • 1
    Upload a JPG, PNG, or WEBP image from your device using the file picker on the home page.
  • 2
    A preview of your image is displayed so you can confirm the correct file was selected.
  • 3
    Click Predict Image. The image is sent to the AI vision model for analysis.
  • 4
    The result is returned with a label, confidence percentage, and a brief description.
Detection Classes
🔥 Fire Detected ✅ No Fire Detected

Each prediction returns one of these labels based on visible evidence in the image. Confidence scores range from 0–100% and reflect the model's certainty in its assessment.
