# State of the art

## Eigen et al 2014

Predicting depth is essential component in understanding the 3D geomentry of a scene. Single image is ill-pose problem reiquiring integration of both global and local information from various cues.

Directly regress on the depth using neural netowrk with 2 components: one that first estimate the global structure of the scene, then a second that refines it using local information.

The network trained using a loss that explicitly accounts for depth relations between pixel locations, in addition to point wise error.

### Ill-posed

A problem for using only a single RGB image to predict full image depth without spatial information.

### Global information

Use an entire image at once, using scale-invariant error to focus attention on spatial relations within a scene rather than general scale.

**Global Coarse-Scale Network**: predict the overall depth map structure using global view of the scene.

1. Using full image as an input
2. Using max pooling to combine information from different part of the image
3. Usage of this pooling is to effectively use cues such as vanishing points, object locations, and room alignment (segmentation and geometry)
4. Consist of 5 feature extraction layers of convolution and max-pooling, followed by two fully connected layers.
5. Use rectified linear unit (ReLU) for activation on 1st to 6th layer, and linear activation on layer 7

### Local information

Local fine scale network, use data from coarse (rough) depth map to align with local details such as object and wall edges

1. Use convolutional layers only along with one pooling stage for the first layer of edge features.
2. 45x45 pixels input run throught the coarse prediction
3. Consist of 3 fine layers and an output layer
4. All hidden layers use ReLU and last is linear
5. Training independently using coarse scale output (do not propagate to global networks)

### Scale-invariant error

Scale invariant error calculates the average scale of the scene, causing relatively 20% inprovement. It calculates the relationship between points in the scene compared to the global scale.

$$
D(y,y^*) = \dfrac{1}{n}\sum_{n}^{i=1}(\log{y_i}-\log{y_i^*} + \alpha(y,y^*))^2
$$

1. Choose a pair of pixel A and B, compare them to each other then to the ground truth.
2. Compared A and B depth C and compared the coresponding depth A and B in ground truth
3. if their comparison is equal or approaching C then give them credit and if it oppose penalized it
4. This will make the shape of the predicted depth the same as the ground truth even if the value depth is not equal
5. The model will learn geometry of the data and care about depth of the object within the data rather than glocal scale depth

### Training Loss

Training loss of this experiment also derived from scale-infariant error.

Dataset used in this experiment is NYU Depth and KITTI
